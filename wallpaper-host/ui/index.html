    壁纸仓库

    从已启用仓库的最新 Release 获取壁纸。默认只启用 Gitee；支持 GitHub、Gitee 地址和 .git 后缀。

    保存后开关生效，刷新时只访问已启用的仓库。相同壁纸 ID 按列表顺序优先展示。关闭或移除仓库会保留已下载的壁纸。

    网络代理

    支持 HTTP、HTTPS、SOCKS5、SOCKS5H，暂不支持用户名和密码。

    优先使用代理环境变量，未设置时读取 Windows 系统代理；不支持 PAC 自动配置脚本。

    用于壁纸库、在线封面、壁纸下载和程序更新。保存后从下一次请求生效，正在进行的下载不受影响。
