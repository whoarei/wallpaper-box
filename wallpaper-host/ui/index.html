    仓库规则

    支持 GitHub、Gitee 公开仓库，地址可带 .git 后缀。相同壁纸 ID 按列表顺序优先展示，可用“上移”调整顺序。

    从最新 Release 获取壁纸。关闭或移除仓库会保留已下载的壁纸。

    保存后生效

    网络代理

    用于壁纸下载与程序更新

    使用系统配置的代理连接网络。

    支持 HTTP、HTTPS、SOCKS5 / SOCKS5H

    连接说明

    跟随系统时优先使用代理环境变量，未设置时读取 Windows 手动代理。暂不支持 PAC / WPAD。

    SOCKS5H 由代理解析域名，手动地址暂不支持用户名和密码。保存后从下一次请求生效，正在进行的下载继续使用原配置。
