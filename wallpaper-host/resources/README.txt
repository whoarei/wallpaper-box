壁纸盒子 0.11.0 · Windows x64

语言设置
在“设置 → 常规 → 语言”选择跟随系统、简体中文或 English，选择立即保存。
默认跟随 Windows 界面语言，中文使用简体中文，其他语言使用英语。
管理界面、托盘、内置壁纸和预览同步切换，保持当前画面和暂停状态；未适配的第三方壁纸及远程更新说明保留原文。

首次使用
1. 使用 NSIS 安装程序安装，运行 wallpaper-box.exe；0.3.1 起仅发布安装版。
2. 内置松风镇与静水之间水族箱，点击右上角的显示器缩略图选屏后，再点击壁纸封面即可应用。
3. 不需要 Docker、Node.js、Nginx 或本机 HTTP 服务，断网也可播放已安装壁纸。
4. 程序仍需要 WebView2；安装版会在缺少它时下载 Microsoft 官方运行时。

简洁管理界面
壁纸列表优先展示封面，右上角以各屏当前壁纸的封面显示缩略图；横竖屏比例保留，所选屏幕高亮。
缩略图用于选屏，不会自动更换壁纸；未设置壁纸的屏幕显示占位图。暂停与壁纸提供的互动操作集中在底部常驻播放栏，更多互动可从展开菜单选择。
点击封面一步应用；“预览”在独立窗口播放，不改变当前屏幕壁纸，关闭预览后停止播放。
设置分为“常规、壁纸仓库、网络代理、程序更新”四类，一次只显示一组内容。
“常规”提供语言、随系统启动、自动暂停、文件夹 / ZIP 导入、壁纸目录与重新扫描。
仓库和代理的保存按钮固定在页面底部；详细说明默认收起，切换分类会保留未保存的输入。
新版安装包准备好后只显示提示，由用户在设置中点击“重启并升级”启动安装。
“关于壁纸盒子”位于“设置”底部和托盘右键菜单，提供当前版本、作者、项目主页、问题反馈及主要第三方组件许可信息。

窗口与资源占用
自绘标题栏与导航融合，右上角支持最小化、最大化 / 还原和收起到托盘；标题栏空白和品牌区域可拖动，双击切换最大化。
按钮支持键盘聚焦及 Enter / 空格操作，收起窗口后壁纸继续播放。
底部显示当前屏幕壁纸 WebView2 进程组的 CPU、内存占用，每 5 秒采样，收起或最小化管理窗口后停止采样。
CPU 按整机总算力计算平均比例；内存为专用工作集，不含共享内存和显存。点击读数可查看统计说明。
首次采样和壁纸重载后显示“采样中”，读取失败或无法独立统计时显示“暂不可用”；暂停时仍显示实际占用。

随系统启动
首次运行后默认启用，旧设置也采用此默认值，可在“设置 → 常规”关闭，立即保存，重启和升级后保留。
登录 Windows 时在后台恢复壁纸并留在托盘，不弹出管理窗口；手动打开或左键点击托盘可显示管理窗口。
仅为当前用户设置，无需管理员权限；保留 Windows 任务管理器中禁用启动项的状态，可通过程序开关重新启用。
设置失败会在开关旁提示，不影响壁纸播放；正常卸载会移除启动项。

避开任务栏
壁纸按每块显示器的 Windows 可用工作区显示。任务栏位置、大小或显示器布局变化后，约 2 秒内自动调整。

双屏闪烁修复
0.3.2 在桌面层级正常时不再周期性移动壁纸窗口，仅在异常时修复，保持多屏壁纸顺序稳定。
升级保留用户壁纸和显示器设置，无需重新下载壁纸。

水族箱投喂
直接左键单击水族箱所在屏幕的桌面空白水面，即可在点击位置投喂。
也可选择正在播放水族箱的显示器，点击管理窗口或托盘菜单中的“投喂鱼儿”。
入口只在该屏幕使用水族箱时显示；手动暂停时请先继续播放。
遮挡自动暂停时仍可投喂，回到桌面后鱼儿会继续游动进食。
加载未完成、页面自身暂停或鱼食还没吃完时，程序会提示原因。
壁纸模式保持鼠标穿透；宿主只观察鼠标，将确认的桌面空白短点击转发给网页。
图标、任务栏、其他窗口、菜单、拖拽以及 Ctrl / Shift / Alt 点击不触发壁纸。
松风镇也可点击空白处种花；程序不安装键盘钩子或全局快捷键，E 键仅用于浏览器独立页面。
保留 0.2.1 的宿主投喂修复，无需更新壁纸库；两张内置壁纸仍为 1.0.0，最低程序版本仍为 0.2.0。

程序在线升级
启动先重新验签缓存，再延迟 5 秒检查；持续运行每 60 秒观察本地日期，每天检查一次。
失败不会在当天后台循环重试，可手动检查或等待下一天、下次启动。
发现新版本会自动后台下载安装包，并用内置公钥校验 Ed25519 更新签名和版本绑定。
下载期间壁纸照常播放；下载或校验失败不影响当前程序与本地壁纸。
准备完成后只提示可升级；点击“重启并升级”即退出并启动已验证的安装程序，不再弹出二次确认。
未点击升级按钮时继续使用当前版本；安装升级保留已下载壁纸和每块显示器的选择、暂停设置。
官方入口：https://github.com/whoarei/wallpaper-box/releases/latest/download/latest.json
0.2.x 没有程序升级器，须先手动安装一次 0.3.2，后续版本才能在线升级。
不再发布便携包，也不提供便携版在线升级。

在线壁纸
每次点击“发现”会自动刷新已启用仓库的在线清单，已有缓存时也会刷新；刷新中重复点击不会重复请求，仍可用“刷新壁纸库”手动刷新。
“发现”使用毛玻璃卡片。点击卡片版本号展开正式 Release 中的历史版本，点击目标版本即可下载并替换，无需额外确认。
可继续加载“更早版本”；不兼容当前程序的版本不可下载。取消或失败保留原版本，重试仍下载原先选择的版本。
校验并安装成功后，正在使用该壁纸的屏幕自动刷新；未使用的壁纸仍需手动应用。
默认壁纸仓库：https://gitee.com/xishuaiya/wallpapers
原 GitHub 壁纸仓库：https://github.com/whoarei/wallpapers，默认关闭，可按需启用。
程序中的“发现”可刷新已启用仓库、下载、安装和更新壁纸，公开仓库无需登录。
设置中可添加、移除和排序 GitHub/Gitee 仓库，支持 .git 后缀，每项有独立开关。
保存仓库设置后生效；默认展示已启用仓库最新稳定 Release 的清单、封面和 ZIP，历史版本按选择下载。
同一壁纸 ID 按仓库顺序优先展示；每个仓库独立缓存，失败保留缓存并提示。
关闭或移除仓库会隐藏其在线结果，保留已下载壁纸和当前播放；允许关闭全部仓库。
检查只获取清单与封面，用户点击某张壁纸后才下载对应 ZIP，不自动下载全库。
最多同时处理 5 项下载，超出的按加入顺序等待，空出位置后自动开始。
进度、大小与速度直接显示在壁纸卡片；鼠标悬停或键盘聚焦时可取消下载、移出等待项，失败项常显重试。
右上角任务数量可筛选发现页的相关卡片，没有独立下载面板；新壁纸完成后由用户选择应用。
取消会停止连接并保留已有壁纸，安装阶段不能取消。关闭程序会停止本次下载，队列不跨重启保存。
下载包会核对大小与 SHA-256，并在临时目录完成资源检查后才切换版本。
下载或安装失败不会覆盖正在使用的旧版本。已安装壁纸可断网播放，并可回退上一版本。
更新壁纸只需内容仓库发布新版本，不必重新安装壁纸盒子程序。

松风镇桌面控制
桌面保留昼夜、天气、小火车与帮助控制栏；静止片刻后淡出，移动鼠标到桌面空白处可唤回。
控制栏被桌面图标遮挡时需先移开图标；页面控制栏和主程序各自保留暂停状态，恢复主程序不会清除页面暂停。
控制栏、帮助和桌面适配由壁纸页面负责。两张内置快照更新为 1.0.1；已下载旧包的管理端互动操作需要更新内容包后提供。

网络代理
设置中可选择跟随系统、手动代理或直连，默认跟随系统。
跟随系统优先读取代理环境变量，没有对应变量时读取 Windows 手动代理。
手动支持 HTTP、HTTPS、SOCKS5、SOCKS5H 地址；SOCKS5H 通过代理解析域名。
可先测试连接再保存；保存后从下一次请求生效，已有请求继续使用原配置。
壁纸库、封面、壁纸包和程序更新统一遵守代理设置，失败不会自动改为直连。
目前不支持 PAC/WPAD，手动代理地址不支持用户名和密码。

自定义壁纸
在“设置 → 常规”的“本地壁纸”中选择文件夹或 ZIP 导入，也可打开用户壁纸目录，把模块放入 local/<模块名>/。
最小模块只需 index.html；可选 module.json、cover.jpg，以及相对路径的 JS / CSS / 图片 / 字体资源。
目录变化后列表和托盘自动更新，自定义内容不会覆盖内置壁纸。

壁纸目录
内置：程序目录下 wallpapers/，随程序升级。
用户壁纸：%LOCALAPPDATA%/WallpaperBox/wallpapers/
local/ 保存自定义模块，online/ 保存下载的独立版本及激活记录。
升级时保留用户壁纸目录，不用重新下载已有壁纸。

托盘操作
左键打开管理界面；右键菜单显示所选显示器，可展开切换。
“壁纸”子菜单集中列出可选壁纸；“壁纸 → 壁纸操作”提供当前壁纸的互动、暂停和关闭当前屏幕壁纸。
全部暂停 / 继续、显示 / 还原桌面与退出保留在一级菜单；自动暂停、程序更新和关于信息位于“设置与帮助”。
关闭管理窗口会收起到托盘。“退出壁纸盒子”结束程序并恢复原桌面。
显示器选择、壁纸选择与暂停设置继续保存在 %APPDATA%/local.screen-garden.wallpaper/。
程序更新缓存位于上述目录的 app-updates/，与用户壁纸目录分开，重启后会重新验签。
